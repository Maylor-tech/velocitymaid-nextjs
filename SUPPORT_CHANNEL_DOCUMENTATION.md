## 📋 Support Rules

### Rule 1: One Official Channel

**All support requests must go through the official channel.**

- ✅ Use official channel for all issues
- ❌ No WhatsApp problem-solving
- ❌ No side-channel resolutions
- ❌ No direct phone calls (unless emergency)

### Rule 2: Everything Logged

**All support requests must be logged in the system.**

- Create ticket/issue for every request
- Track response time
- Document resolution
- No off-the-books fixes

### Rule 3: Response Time SLA

**We respond within [X] hours.**

- [ ] 24 hours (recommended for pilot)

- [ ] 4 hours
- [ ] Other: [SPECIFY]

## 🔄 Escalation Path

### Customer Escalation

**Level 1: Support Channel**
- Customer submits request via official channel
- Support responds within SLA
- Resolve or escalate

**Level 2: Admin Review**
- Complex issues escalated to admin
- Admin reviews and responds
- May involve Branch Owner if needed

**Level 3: Executive**
- Critical issues only
- Business-impacting problems
- Rare escalation

### Cleaner Escalation

**Level 1: Support Channel**
- Cleaner submits request via official channel
- Support responds within SLA
- Resolve or escalate

**Level 2: Branch Owner**
- Job-specific issues
- Assignment problems
- Branch Owner reviews

**Level 3: Admin**
- Payment issues
- Account problems
- Policy questions

### Branch Owner Escalation

**Level 1: Admin**
- Operational issues
- System problems
- Policy questions

**Level 2: Executive**
- Critical business issues
- Expansion decisions
- Rare escalation

## 🚫 What NOT to Do

### ❌ Don't Do These:

- **No WhatsApp problem-solving**
  - Don't resolve issues via WhatsApp
  - Don't make exceptions via WhatsApp
  - All issues go through official channel

- **No side-channel resolutions**
  - Don't fix things "off the books"
  - Don't bypass the system
  - Everything must be logged

- **No manual overrides without documentation**
  - If override is needed, document why
  - Get approval first
  - Log the override

- **No promises we can't keep**
  - Don't promise exact times
  - Don't promise specific outcomes
  - Be honest about limitations

---

## ✅ What TO Do

### ✅ Do These:

- **Use official channel only**
  - All requests through official channel
  - All responses through official channel
  - Everything logged

- **Set clear expectations**
  - "We'll respond within [X] hours"
  - "We'll investigate and get back to you"
  - "Here's what we can do"

- **Document everything**
  - Log all requests
  - Track resolution time
  - Document outcomes

- **Escalate when needed**
  - Don't try to fix everything yourself
  - Escalate complex issues
  - Get help when stuck

## 📋 Support Request Template

**When logging a support request, include:**

1. **Requestor:** Customer / Cleaner / Branch Owner
2. **Issue Type:** Booking / Payment / Job / Account / Other
3. **Description:** Clear description of the issue
4. **Priority:** Low / Medium / High / Critical
5. **Response Time:** Track actual vs. SLA
6. **Resolution:** How it was resolved
7. **Follow-up:** Any follow-up needed
