Icon-only square button for toolbars, drawers, and card actions. Pair with a Lucide icon child and always set `aria-label`.

```jsx
<IconButton aria-label="Close" variant="ghost"><X /></IconButton>
<IconButton aria-label="Add" variant="cyan"><Plus /></IconButton>
```

Variants `navy | cyan | outline | ghost`; sizes `sm | md | lg`.
