The surface primitive for grouped content — pricing tiles, KPI panels, list rows, drawers.

```jsx
<Card elevation="feature" highlight interactive>
  <CardTitle>Deep clean</CardTitle>
  <CardDescription>Thorough top-to-bottom clean.</CardDescription>
</Card>
```

`elevation`: `flat` (hairline border), `raised` (default soft shadow), `feature` (large radius + lift, for marketing). `highlight` adds the cyan emphasis ring. `interactive` lifts on hover. `padding`: `none | sm | md | lg`.
